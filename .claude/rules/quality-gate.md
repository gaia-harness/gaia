# Quality Gate

Before any `git commit` that touches source, run the Quality Gate - unless it has nothing to check (the page's `## When to skip the gate` decides). The gate's value-set step runs on every commit, even one whose other steps the page skips. When the gate applies, **read `wiki/decisions/Quality Gate.md` and run its steps as written; do not rely on a remembered gate.** The page is the source of truth for the steps, skip logic, and rationale. Fix all warnings before reporting. STOP and report before committing, except inside a workflow whose own instructions commit without stopping, such as the fix round of `wiki/concepts/Audit Round Procedure.md` (`#### The fix round: fixer, verifier, gate`); step 10 of the page names the rest. There the workflow's own checkpoint is the review point.
